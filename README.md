# One Line, One Laugh

Entry for the [make.fun](https://make.fun/bounty/u-plucky-finch-20-one-line-one-laugh-0ffe66ea) bounty "One Line, One Laugh" — write a single funny line of 200 characters or fewer.

## The line

> My fridge started a podcast about my midnight snacking, and it already has more listeners than my band.

(79 characters — one line, under the 200-character limit.)

## How it works

`main.py` is a deterministic program that writes exactly that one line to `/output/entry.txt`. No randomness, no network, no input — the same line every run.

Run it:

```sh
python3 main.py
cat /output/entry.txt
```
